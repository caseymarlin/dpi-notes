Image DPI Cheat Sheet

DPI is metadata about print density — not a magic sharpness knob. This page covers the formula, common print sizes, and how to change DPI without re-encoding pixels.

The only formula that matters

print inches = pixels ÷ DPI (per side). A 2400×3000 px photo at 300 DPI prints at 8×10 in. At 72 DPI the same pixels claim ~33×42 in — soft on paper, fine on a screen.

DPI vs PPI vs “export quality”

TermWhat it isWhen it matters
DPIDots per inch — print metadata in JPG/PNG (JFIF / EXIF / pHYs)Print shops, Word/InDesign layout
PPIPixels per inch — same math, often used for screensCSS resolution, design tools
JPEG qualityCompression of pixel dataFile size / artifacts — unrelated to DPI tags

Raising DPI without adding pixels does not invent detail. Upsampling (adding pixels) is a different job.

A4 is 210×297 mm ≈ 8.2677×11.6929 in. Rounding inches first (8.27×11.69) yields 2481×3507 at 300 DPI — one pixel off. Prefer the millimetre path when a print house specifies A4.

Where DPI lives in the file

  • JPEG: JFIF density and/or EXIF XResolution / YResolution (unit = inches).
  • PNG: pHYs chunk (pixels per metre; 300 DPI ≈ 11811 pm).
  • Screens ignore it: browsers display by CSS pixels; the tag only shows up in “image info” or print pipelines.

Changing DPI without re-encoding

Rewrite only the density fields; leave the compressed pixel bitstream untouched. That keeps quality identical and avoids another JPEG generation-loss pass.

Need to do it in the browser? SetDPI changes JPG/PNG DPI locally (nothing uploads). For the pixel table, see 300 DPI in pixels or the DPI calculator.
